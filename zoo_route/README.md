# 动物园亲子游线路推荐系统

家长选择**入口、想看的动物区、午餐点、出口**，系统综合考虑
**距离、坡度、儿童车友好度、道路拥挤度与表演时间**，
推荐一条**半日游路线**（含时间轴行程单）。
管理员可维护园区**节点、道路连接与实时拥挤程度**。

纯 Python 标准库实现，零第三方依赖；测试基于 `unittest`（也可被 `pytest` 直接运行）。

```
zoo_route/

│   ├── admin.py      # 管理员后台：节点/道路/拥挤度维护、园区校验
│   ├── data.py       # 示例动物园（2 门、7 动物区、2 餐厅、23 段道路）
│   └── cli.py        # 命令行演示入口
├── data/zoo_sample.json   # 示例数据（JSON 快照）
└── tests/                 # 28 个算法与功能测试
```

## 快速开始

```bash
cd zoo_route

# 默认场景：正门进、东门出，看熊猫/长颈鹿/猛兽/企鹅，湖畔餐厅午餐
python3 -m zoo.cli

# 自定义场景
python3 -m zoo.cli --zones panda,monkey,aquarium --lunch rest_forest \
    --exit gate_main --start 10:00 --no-stroller --no-shows

# 管理员演示：午高峰上调拥挤度 → 自动重新规划
python3 -m zoo.cli --demo-admin

# 运行全部测试
python3 -m unittest discover -s tests -v     # 或安装 pytest 后: pytest
```

## 算法说明

**1. 边代价模型**（`planner.edge_cost`，权重均可配置）

```
代价 = 距离 × (1 + 0.08×坡度%) × (1 + 1.5×拥挤度) × (婴儿车不友好 ×5)
耗时 = 距离 ÷ (步行速度 × 坡度减速 × 拥挤减速)
```

**2. 两阶段规划**

1. **路径层**：对所有目标点（入口/出口/动物区/餐厅）两两跑加权
   Dijkstra，得到代价-耗时矩阵；
2. **顺序层**：枚举动物区访问顺序（≤8 个全排列；>8 个自动切换
   贪心最近邻 + 2-opt），午餐点尝试每个插入位置，对每个候选方案
   做**时间轴模拟**：
   - 到达动物区时，若下一场表演在等待上限内 → 等候并观看
     （加分奖励，等待按分钟计罚）；
   - 午餐开始时间偏离 11:30–13:00 窗口 → 按分钟计罚；
   - 总时长超出半日预算（默认 300 分钟）→ 按分钟计罚并给出警告。

**3. 输出**：按总得分最低的方案生成逐段时间轴行程单
（步行段、游览、表演、午餐、警告）。

## 管理员功能（`ZooAdmin`）

| 功能 | 接口 |
|---|---|
| 节点增删改 | `add_node / update_node / remove_node`（删节点级联删道路） |
| 道路增删改 | `add_edge / update_edge / remove_edge` |
| 拥挤度 | `set_congestion(a, b, 0~1)`、`congestion_report()` |
| 园区校验 | `validate()`：检查大门存在、所有节点可达、距离为正 |
| 持久化 | `save(path)` / `ZooAdmin.load(path)`（JSON） |

## 测试覆盖（28 个用例）

- **最短路**：婴儿车绕开不友好路段、拥挤/坡度抬升代价、不可达报错
- **路线规划**：必经点与起终点、午餐落在窗口内、表演衔接与等待上限、
  半日时长预算与超时警告、时间轴单调性、非法输入
- **贪心回退**：>8 个动物区时贪心+2-opt 仍覆盖全部目标，
  且得分与全排列最优解对比在容差内
- **管理员**：CRUD、拥挤度边界校验、孤岛检测、拥挤影响重规划、
  JSON 保存/加载往返一致
